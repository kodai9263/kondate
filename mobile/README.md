# スマホアプリ技術検証

仕様書は`docs/mobile-app-spec-2026-09-22.md`。この作業は、買い物リストの認証付き表示と、iOS／Android向けの配布基盤が成立するかを調べる段階。

## 起動

1. `npm ci`
2. `.env.example`を参考に`.env.local`へ公開可能なSupabase URLとpublishable／anonキーを設定する。秘密鍵は入力しない。
3. リポジトリ側でNext.jsの開発サーバーを3000番に起動する。
4. このディレクトリで`npm run dev`を実行する。開発画面の`/api`は3000番のNext.jsへ転送される。

端末向けのビルドは、`VITE_API_BASE_URL`に本番または検証用のHTTPSアプリURLを設定して`npm run build`する。その後`npm run cap:sync`で同梱資材を更新する。`VITE_API_BASE_URL`が未設定またはHTTPS以外ならビルドを止める。開発用のVite URLを端末向けビルドに埋め込まない。

## この段階の確認範囲

- メール・パスワードでログインし、同じ家族の買い物リストを表示する。品物のチェック、手動追加・削除、期間変更、完了・取り消しを既存の保存処理へ送る。
- チェック済みと手動追加を区別して表示する。
- 通信が途切れても、アプリを開いたままなら最後に取得したリストを表示する。
- ログイン状態・リストは永続保存しない。終了・再起動後は再ログインが必要。
- 通知、購入・復元、退会は後続段階。圏外では買い物の変更を保存しない。

認証情報の安全な保存領域、再起動後の圏外閲覧、課金接続には追加実装が必要。開発者登録と実機検証も別途必要。

現在の作業ホストにはXcodeとAndroid Studioを導入済み。両OSのネイティブビルドは成功した。iPhoneシミュレーターではログイン画面の表示まで確認したが、実機起動は未確認。
