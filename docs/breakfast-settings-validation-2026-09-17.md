# わが家の朝食：実装と検証

2026-09-17。仕様承認に基づくローカル実装を完了。本番DB適用・公開・GitHubへのpush・PR作成は未実施。

## 実装内容

- 設定の朝食を独立したカードに変更。通常は登録済みの名前だけを表示。
- 「朝食を追加」で10種類の定番を直接表示。選択すると入力済みの編集欄が開き、コピーをそのまま追加／アレンジできる。自作も可能。
- 名前と買うものを基本欄、工程と目安時間を任意の詳細欄に分離。並べ替え・取消し・候補から外す・定番への復元・オン／オフを実装。
- 家庭ごとの有効日と版を保存し、編集は日本時間の翌日から反映。今日の確定レシピと工程チェックを保持。同時保存は版の不一致で拒否。
- 朝食だけを確定する `ensure_today_breakfast` を追加。夕食候補のない日に夕食を自動補充せず、朝食のチェックを利用できる。
- 買い物の対象週に登場する朝食から品名を集約。朝食分は数量を自動計算しない。削除・再追加で古い購入済み状態を流用しない。
- 家族の参加・共有解除・利用プランを保存と読み出しで確認。確定朝食は夕食メニュー一覧・献立候補に混ぜない。

## 固定買い物リストの照合

`menu-data.json` の4週間の夕食・副菜・材料・工程を照合し、朝食との混在部分を `src/lib/breakfast/shopping.ts` で置換する。元のデータファイルは変更しない。

| 品目 | 扱い |
|---|---|
| 食パン・バナナ・ヨーグルト | 固定分を除き、家庭の朝食設定から追加 |
| 卵 | 第1週はハンバーグ用1個、第2週は親子丼用（分量未記載）、第3週は炒り卵用4個、第4週はピカタ用2個を残す。第1週の温泉卵5個は別品目のまま残す |
| 牛乳 | 第1週のハンバーグ用大さじ2を残す。他週の固定2本は除く |
| ミニトマト | 第1・2・4週の副菜分を品名で残す。第3週はタコライス用のトマト2個を残し、別途載っていたミニトマトを除く |
| 紅生姜 | 第4週の牛丼用として夕食側へ移す |
| 豆腐・油揚げ・チーズ等 | 夕食分を維持。朝食の材料と勝手に合算しない |

夕食側の基本の買い物リストは従来どおり固定テンプレートを基にする。月間献立から夕食の材料を作り直す変更は今回の範囲に含まない。
