# 無料モニター募集 運用原稿

## 募集の前提

- 対象: 平日の夕飯を用意している家庭
- 募集枠: 10家庭
- 利用期間: 約2週間
- 費用: 無料、カード登録不要、自動課金なし
- お願い: 終了後の5分程度のアンケート
- 募集URL: 公開後の `/monitor` のURLに差し替える

## 知人へ送る文章

平日の夕飯を考える負担を減らす「きょうのごはん」というアプリを作っています。

4週間の献立をまとめて決めて、当日は仕込みと調理の段取りを見るだけにするアプリです。買い物リストや家族との共有も試せます。

もっと使いやすくしたいので、普段の生活の中で2週間ほど無料で試してくださるご家庭を10家庭募集しています。カード登録や自動課金はありません。最後に5分程度、率直な感想を教えていただけるとうれしいです。

興味があれば、こちらから内容を確認できます。

【モニター募集URL】

## SNS投稿文

「今日の夕飯、何にしよう」を毎日考えなくて済むように。

献立・仕込み・買い物を家族で進めるアプリ「きょうのごはん」の無料モニターを10家庭募集します。

- 4週間の献立をまとめて作成
- 今日の仕込みと調理手順を確認
- 買い物リストを家族と共有
- カード登録不要、自動課金なし

約2週間使ったあと、5分程度の感想をお願いします。

【モニター募集URL】

## 2週間後アンケート

1. この2週間で、何日くらい使いましたか？
2. 最もよく使った画面や機能はどれですか？
3. 使う前と比べて、献立を考える負担は減りましたか？（5段階）
4. 買い物や仕込みを家族と共有できましたか？
5. 使い方が分からなかったところはありましたか？
6. 使わなかった日があれば、その理由を教えてください。
7. このまま使い続けたいですか？（使いたい・迷う・使わない）
8. 月480円の家族プランを使いたいと思いますか？その理由も教えてください。
9. 友人や家族へ勧めるとしたら、どのように説明しますか？
10. 改善してほしいことを1つだけ挙げるとしたら何ですか？

## 集計する数字

- モニター募集ページの閲覧数
- 献立デモを押した人数
- 無料登録を押した人数
- `signup_source = monitor` の登録者数
- 初回の献立生成まで到達した家庭数
- 2週目にも利用した家庭数
- 家族招待を行った家庭数
- 継続意向が「使いたい」だった家庭数
