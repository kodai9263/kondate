# 初心者向けメニューの追加検証

この文書は前回の検証時点の記録です。最新の結果は[全95品の再点検記録](menu-recheck-2026-09-16.md)を参照してください。

2026年9月16日。対象は公式94品と「なすの豚しゃぶ香味だれ」1品。

## 結果

95品の材料・工程・注意書きを再点検し、矛盾や判断の抜けを修正した。追加検証中に本文・注意書き・時間を修正した公式料理は53品。全体は公式726工程、共有7工程のまま。

自動テスト158件、隔離したデータベースで26項目、型・コード検査、本番用ビルドが成功した。確認用画面の検索・展開と、修正した説明の表示も確認した。

**これは文章・計算・保存・表示の検証であり、初心者による実調理の成功を確認したものではない。本番への反映も未実施。**

## 見つかった問題と修正

| 問題 | 修正 |
| --- | --- |
| くし形の等分数や、厚さと切り方の補足が食い違う | 豚のしょうが焼きなどの切り方を統一。きのこと牛肉の混ぜご飯のかぶは厚さ5mmの半月切りに修正 |
| グリル・オーブン料理の追加加熱に、ふたをして弱火という説明が残る | さわらはグリルで1〜2分ずつ、あじの香草パン粉焼きはオーブンで2分ずつ。器具を移す場合も明記 |
| 炊き込みご飯のだしと水が二重に読める | たけのこご飯の炊飯用の水を除き、調味料を先に入れて液体のだし汁を目盛りまで加える手順に統一 |
| 生米から炊く料理に「炊いたご飯を用意済み」の注意が混在 | あじの南蛮漬け・冷しゃぶの注意書きを修正 |
| 人数変更で米が半端な合数になった場合の水量・機器容量が不明 | 生米を使う7品に、対応する目盛りと炊き込み容量の確認を追加 |
| 浸水30分＋炊飯45〜60分に下ごしらえを加えると95分では余裕がない | たけのこ・とうもろこし・栗の鶏炊き込みご飯を110分の目安に修正。実測値ではない |
| 汁物を煮た後、主菜を作る間に火を止める指示が不足 | 該当する汁物に火を止めるタイミングと食べる前の温め直しを明記。冷水から加熱する一部の汁物は、沸いてから時間を数えるよう修正 |
| ブレンダーや油用温度計を道具一覧から確認できない | 道具一覧に追加。ピーラー・竹串・トングも工程に応じて表示 |
| ポタージュの熱い汁を扱う条件、揚げ油の量が曖昧 | ブレンダーの対応温度まで冷ます指示、刃を沈めて使う指示を追加。揚げ油は深さ3cmを目安とし、鍋・コンロ指定の最低油量を優先 |
| 一覧に複数料理を表示すると材料欄の見出しIDが重複 | 表示ごとに固有のIDを付与し、ブラウザでも重複0件を確認 |

材料名の検索だけでは「新玉ねぎ→玉ねぎ」「カットトマト→トマト」「ミックスビーンズ→豆」のような呼び方の違いを誤検出するため、該当工程も読んで確認した。名前が出てくることだけで料理として成立するとは判定していない。

## 実行した検証

| 検証 | 確認できた範囲 |
| --- | --- |
| 全95品の表示テスト | 材料と最後の工程まで描画できる。番号付き工程、基準人数を表示 |
| 全95品 × 1〜16人分 | 全材料行の数値が指定人数に比例する。材料名が変わらず、分数・少量調味料・重量・個数・合数を換算できる |
| 今回の不具合の再発防止 | 炊飯済み前提の混在、切り方、器具別の追加加熱、汁物の火止め、特殊な道具、油量を検査 |
| 自動テスト全体 | 30ファイル・158件成功。別の作業用コピー `.claude` は除外 |
| データ更新：11項目 | 対象95品、4人分の基準、材料・工程の一致、家庭アレンジ・対象外共有品の保護、チェック状態、同一更新の再適用 |
| 保存・再取得：15項目 | 本番と同じ保存関数で朝・夜の複数工程を保存。改行、材料維持、献立からの再取得、再編集、重複防止、元に戻す操作、別家庭からの閲覧・変更拒否 |
| 型・コード検査 | TypeScript・ESLint成功 |
| 本番用ビルド | 成功。一時的な確認用アプリページは残していない |
| ブラウザ | 実際の表示部品から作ったローカルHTMLで検索・展開を操作。菜の花と鶏肉、南蛮漬け、香草パン粉焼き、たけのこご飯の修正内容を確認 |
| 狭い幅 | 375pxのコンテンツ幅で、たけのこご飯の長い材料・工程に横方向のはみ出し0件。目視でも確認。スマートフォン実機・375pxの画面全体での検証ではない |

データベースは一時的なローカルPostgres。本番や既存DBへ接続していない。AuthとRealtimeの外部サービスは代替実装であり、ログイン済みブラウザからの保存や家族間同期を検証したものではない。

### 加熱条件との照合

肉の中心75℃・1分以上という説明を[厚生労働省の肉の加熱に関する案内](https://www.mhlw.go.jp/stf/web_magazine/closeup/08.html)と照合した。牡蠣の中心85〜90℃・90秒以上という説明は[厚生労働省のノロウイルスQ&A・Q15](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/shokuhin/syokuchu/kanren/yobou/040204-1.html)と照合した。記載温度・時間を実際の料理で達成できたかは未実測。
