# 週間・月間献立の実装と確認（2026-09-26）

## 変更内容

- 献立画面の「週間／月間」切り替え。通常は今週、従来の `?month=YYYY-MM` は月間表示。
- 月曜〜日曜の週間一覧：主菜・副菜・完成までの時間、変更・固定。
- 月間カレンダー：日付から詳細・変更・固定・「この週を見る」。
- 前後の週・月への移動、今週・今月への復帰、日本時間の今日表示。
- 月をまたぐ週は両月の保存済み献立を取得。保存は変更した日が属する月だけに行う。
- 固定操作でも他の日の料理を維持。保存エラー時は変更を適用せず、再試行できる。
- 読み込み失敗時は編集画面を出さない。既存のアレルギー・献立評価・40分制限を維持。
- 最新mainにある副菜の変更・なし・自作登録を維持。週間・月間の切り替えや固定時も副菜設定を保存する。
- DBスキーマと保存用Server Actionの変更はなし。ナビゲーション表記は「献立」に統一。
